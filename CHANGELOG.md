## [0.1.0] - unreleased

Initial release. The library, the `cherrypi-fetch` CLI and the renderer
behaviour that lived in CherryPi's `crates/servo-fetch`: synchronous XHR
proxying, a clean state before every render, the Windows Firefox default user
agent, snapshot generations, one Servo per process, bounded output and the
documented exit codes.
